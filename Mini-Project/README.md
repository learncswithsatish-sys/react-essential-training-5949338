# Mini-Project

This folder contains two small starter apps and interview resources:

- `react-mini-app/` — a lightweight React app built with Vite.
- `next-mini-app/` — a small Next.js app using the App Router.
- `Interview-Questions.md` — React and Next.js interview questions with examples.

## Run the projects

### React app

```bash
cd Mini-Project/react-mini-app
npm install
npm run dev
```

### Next.js app

```bash
cd Mini-Project/next-mini-app
npm install
npm run dev
```
